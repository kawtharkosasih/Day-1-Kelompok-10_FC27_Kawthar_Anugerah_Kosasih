# Dokumentasi Day 1 Proyek Workshop

## 1. Rangkuman Materi

### A. Prompt Engineering

Prompt Engineering merupakan cara menyusun instruksi atau perintah kepada AI agar menghasilkan jawaban yang sesuai dengan kebutuhan. Dalam membuat prompt, terdapat empat unsur penting, yaitu:

- **Role:** Menentukan peran AI.
- **Task:** Menjelaskan tugas yang harus dilakukan AI.
- **Context:** Memberikan informasi atau latar belakang yang dibutuhkan.
- **Format:** Menentukan bentuk jawaban yang diinginkan.

### B. Git dan GitHub

Git merupakan sistem version control yang digunakan untuk mencatat dan mengelola perubahan pada file secara lokal. Sementara itu, GitHub merupakan platform daring yang digunakan untuk menyimpan repository Git serta mendukung kolaborasi dalam pengembangan proyek.

### C. Alur Kerja Git

Dalam Git, terdapat tiga bagian utama:

1. **Working Directory:** Tempat pengguna membuat atau mengubah file.
2. **Staging Area:** Tempat menyiapkan perubahan yang akan disimpan.
3. **Git Directory/Repository:** Tempat Git menyimpan riwayat dan data perubahan yang telah di-commit.

### D. Perintah Dasar Git

| Perintah | Fungsi |
|---|---|
| `git init` | Membuat repository Git lokal baru. |
| `git add .` | Menambahkan seluruh perubahan ke staging area. |
| `git commit -m "message"` | Menyimpan perubahan ke dalam riwayat Git. |
| `git push` | Mengirim commit ke repository remote seperti GitHub. |

## 2. Poin Penting dan Pengetahuan Baru

Berdasarkan materi yang dibagikan, terdapat beberapa pengetahuan penting yang dapat dipahami:

- Prompt yang jelas dan terstruktur dapat membantu AI menghasilkan jawaban yang lebih sesuai dengan kebutuhan.
- Git dan GitHub memiliki fungsi yang berbeda, tetapi dapat digunakan bersama dalam pengembangan proyek.
- Git memungkinkan perubahan kode dilacak sehingga riwayat pengerjaan dapat dikelola.
- Visual Studio Code dapat digunakan sebagai lingkungan kerja untuk mengelola kode dan menjalankan perintah Git.
- Penggunaan AI dan version control dapat membantu proses pengembangan perangkat lunak menjadi lebih terorganisasi.

## 3. Pendapat Pribadi tentang Day 1 Proyek Workshop

Materi Day 1 Proyek Workshop memberikan gambaran mengenai beberapa kemampuan dasar yang penting dalam pengembangan proyek teknologi. Selain itu, pemahaman mengenai Git dan GitHub menjadi hal penting karena proses pengembangan proyek membutuhkan pengelolaan perubahan dan dokumentasi yang terstruktur.
